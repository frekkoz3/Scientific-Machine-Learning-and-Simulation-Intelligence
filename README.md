# Scientific Simulation and Simulation Intelligence

This repository contains the course material (and practical tutorials) for the academic course of **Scientific Machine learning and Simulation Intelligence** held by professors F. Cairoli and N. Tonicello @ University of Studies of Trieste.

The repository is updated on a weekly basis.
